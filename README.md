# Dice Math Game 🎲

A simple Python + Pygame-based math game where you count the total on dice before time runs out!

## 🚀 How to Run

1. Clone the repository:
```git clone https://github.com/ByteCrafterVeb/dice_math_game.git```
```cd dice_math_game```

2. Install dependencies:
```pip install -r requirements.txt```

3. Run the game:
```python main.py```

## 🔊 Sounds
Make sure `dice_roll.wav` and `tick.wav` are in the same folder as the script.

## 🎮 Features
- Dice randomization and drawing
- Timer-based math challenge
- Reward/Penalty scoring
